# relation-app-practice

## 概要

COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。
リレーションシップを用いてタグからポストやコメントを見れる内容を作った。
ポストとタグの関係性を構築した。

## 使用技術

- PHP 8.x
- Laravel 10.x
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL

## 学んだこと

- １対多の関係のリレーションシップの構築の仕方を学んだ。
- マイグレーションとモデルの書き方。-前回学んだことを生かして、ユーザーが入力した内容をデータベースに格納する方法を活用できた。
